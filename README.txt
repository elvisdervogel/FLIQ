CUT! – The Movie Quiz · eigenständige Version
================================================

Diese 6 Dateien sind die komplette App:
  index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png

So stellst du sie auf GitHub Pages online (geht direkt auf dem iPad in Safari):
 1. ZIP in der Dateien-App antippen, dann wird sie entpackt.
 2. github.com öffnen, kostenloses Konto anlegen und anmelden.
 3. Oben rechts auf „+“ → „New repository“. Name: cut · Public · „Create repository“.
 4. Auf „uploading an existing file“ tippen → die 6 Dateien auswählen → „Commit changes“.
 5. Im Repository: Settings → Pages → Source „Deploy from a branch“ → Branch „main“, Ordner „/ (root“) → Save.
 6. 1–2 Minuten warten. Deine App liegt dann unter: https://DEIN-NAME.github.io/cut/
 7. Die Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Danach startet CUT! wie eine App, im Vollbild und auch ohne Internet.
Updates: einfach die neue index.html im Repository hochladen und die alte ersetzen.
Hinweis: Ein öffentliches Repository und die Seite sind für jeden mit dem Link sichtbar.
